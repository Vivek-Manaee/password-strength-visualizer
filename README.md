# 🔐 Password Strength Visualizer

## 📌 Description
This project is a simple web-based Password Strength Visualizer that dynamically changes the background blur based on the strength (length) of the password entered by the user.

## 🚀 Features
- Real-time password strength feedback
- Background blur effect based on password length
- Clean and responsive UI

## 🛠 Technologies Used
- HTML
- CSS (Tailwind + Custom CSS)
- JavaScript

## ▶️ How to Run
1. Download or clone the repository
2. Open `index.html` in your browser
